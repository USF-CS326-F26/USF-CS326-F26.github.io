# Midterm 2, Section 01, Problem 4: The Shell

**Midterm 2, Section 01**, problem 4 of 5 · **Length:** 10:45 · **Exercise:** `46k_shell` (Week 12) · **Exam:** [Section 01](../assignments/midterm-2-section-01.pdf) (PDF) · **Answer key:** [Solutions](../assignments/midterm-2-section-01-solutions.pdf) (PDF)

Three parts, worked on pages 8 and 9: (a) the value of `cmd`, the value of `arg` and what `exec` does for each typed line, in a table; (b) an `exec` that calls `unwrap()` on `next()`: which lines make it panic, and what the real `exec` does instead; (c) what each of nine commands prints from an empty root, in a table. The answer key's handwriting is written onto the exam page as each step is worked.

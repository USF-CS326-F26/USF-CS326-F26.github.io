### RISC-V Memory Architecture Design

- Described the RISC-V memory map for the course hardware:
  - Physical memory (RAM) begins at a specific base address.
  - Lower regions are reserved for I/O devices (e.g., serial driver, disk controller).
- Outlined the kernel’s free-memory strategy:
  - Break remaining physical memory into 4 KB pages.
  - Track pages on a free list for allocation.
- Emphasized the need to implement a custom allocator (not `malloc`/`free`), requiring some `unsafe` Rust while preserving safety where possible.

### Rust Data Allocation and Storage

- Stack-allocated values: scalars, `struct`s, arrays, tuples.
- Heap-allocated (growable) values: `String`, `Vec<T>`, etc.
  - Stack holds a small handle (pointer, length, capacity).
  - Heap stores the actual buffer.
- Demonstrated vector growth:
  - Allocation and reallocation patterns.
  - When addresses change and when the allocator can reuse space.

### Rust Ownership Rules Overview

- Every value has exactly one owner; the owner drops/releases resources when the scope ends.
- Ownership transfers on assignment or when passing to functions (unless borrowing).
- Rust avoids GC and reference counting by default to ensure deterministic memory management.

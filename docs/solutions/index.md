# Solutions

Exam and practice-set solutions are posted here after each is reviewed in
class.

**Exercise solutions are released with the next exercise.** The reference
solution for an exercise exists in no repository you can fetch until its
completion deadline has passed (Thursday exercises: Thursday 11:59 pm; Friday
exercises: Monday 11:59 pm). It then ships with the next release, into
`exercises/<name>/solution/`, and `oslings update` brings it into your
repository. Print it with:

```sh
oslings solution 33k_paging
```

Before the release, that command tells you the solution is not out yet.

That is deliberate. The exercises are the course, and an exercise whose answer
is a click away is not an exercise. Once the solution is out, reading the
reference version is genuinely worthwhile — it is often shorter than what you
wrote, and the difference is the lesson.

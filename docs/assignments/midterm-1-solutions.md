# Midterm 1 Solutions

Midterm 1 was given on Thursday, October 15, in two versions, one for each
section. Both ask the same five problems with different inputs, addresses and
orders of the options, and two parts differ more than that: 1(c) changes
`bytecopy`'s declaration in a different way, and 4(d) asks for `longest_line` in
Section 01 and `longest_word` in Section 02. Each version is posted here, blank
and with its key, and a video for each problem works the key on that exam's own
pages.

Work the blank exam on paper before you open the key or a video. Reading a
solution feels like learning and mostly is not.

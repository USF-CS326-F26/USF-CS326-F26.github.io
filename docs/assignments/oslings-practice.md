# OSlings Practice Problems

The OSlings practice problems are short paper problem sets on the kernel
exercises. Each is extra credit: [Extra Credit](extra-credit.md#practice) says
how a set earns its share. Each set is posted here, blank and with its answer
key, and a video for each problem works the key on the set's own pages.

Work the blank set on paper before you open the key or a video. Reading a
solution feels like learning and mostly is not.
